# ObsiFolio

[English](./README.md) | [中文](./README.zh.md)

**把 Obsidian 笔记装订成精美的 EPUB 电子书** — 支持文件夹、索引目录、封面与阅读样式。

可导出当前笔记、文件夹、MOC / 索引笔记或整个库；尽量保留双链、Callouts、图片、表格与脚注。导出前可预览，再生成可在 Kindle、Apple Books、KOReader、Calibre 等阅读器打开的 EPUB。导出全程在本地 Obsidian 内完成。

> 要求：Obsidian **1.5.0+** · 桌面端与移动端均可（系统「另存为」仅桌面可用）

---

## 安装（手动）

1. Obsidian：**设置 → 社区插件 →** 关闭「受限模式」。
2. 打开库的插件目录：`.obsidian/plugins/`
3. 从本仓库最新 **Release** 下载 zip，或将以下文件放入名为 `obsifolio` 的文件夹：
   - `main.js`
   - `manifest.json`
   - `styles.css`
4. 最终路径类似：  
   `你的库/.obsidian/plugins/obsifolio/main.js`
5. 回到 Obsidian，刷新社区插件列表并启用 **ObsiFolio**。

**更新：** 用新版文件覆盖该文件夹后，关闭再开启插件（或重启 Obsidian）。
