# ObsiFolio

[English](./README.md) | [中文](./README.zh.md)

**Turn Obsidian notes into polished EPUB ebooks** — folders, indexes, covers, and reading-ready styles.

Export the current note, a folder, an MOC / index note, or the entire vault. Keep Wikilinks, Callouts, images, tables, and footnotes. Preview before you build, then export a standards-friendly EPUB for Kindle apps, Apple Books, KOReader, Calibre, and more. Export runs locally inside Obsidian.

> Requires Obsidian **1.5.0+** · Desktop and mobile (system Save dialog is desktop-only)

---

## Install (manual)

1. In Obsidian: **Settings → Community plugins →** turn off **Restricted mode**.
2. Open your vault’s plugin folder: `.obsidian/plugins/`
3. Download the latest **Release** zip from this repository, or copy these files into a folder named `obsifolio`:
   - `main.js`
   - `manifest.json`
   - `styles.css`
4. Final path should look like:  
   `YourVault/.obsidian/plugins/obsifolio/main.js`
5. Back in Obsidian, refresh Community plugins and enable **ObsiFolio**.

**Update:** replace the files in that folder with the new release, then disable/enable the plugin (or restart Obsidian).
